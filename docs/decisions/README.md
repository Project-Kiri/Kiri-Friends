# Architecture Decisions

Architecture Decision Records capture major product and technical decisions that should remain stable across implementation work.

## Documents

- [0001-watch-iphone-cloud-mac-topology.md](0001-watch-iphone-cloud-mac-topology.md) — accepted Watch, iPhone, Cloud Relay, Mac bridge, and CLI plugin topology.

## When to Add an ADR

Add an ADR when a change affects:

- Runtime topology.
- Communication protocol.
- Security or trust boundaries.
- Persistent data model.
- Deployment architecture.
- Cross-platform ownership boundaries.
