# Product Documentation

Product scope, daily workflow, and information architecture for Kiri Friends.

## Documents

- [information-architecture.md](information-architecture.md) — Navigation model, watch faces, complications, and glanceable information hierarchy.

## Product Principles

1. **Glance First**: The watch app must answer "what is my CLI doing?" within 2 seconds of raising the wrist.
2. **Quick Actions**: Common commands (stop, restart, send prompt) should be accessible within 2 taps.
3. **Phone Fallback**: Complex configuration and history browsing live on the iPhone companion app.
4. **Respect the Platform**: Use native watchOS patterns (complications, notifications, Digital Crown) rather than porting iPhone UI.
