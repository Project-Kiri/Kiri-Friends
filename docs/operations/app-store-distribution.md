# App Store Distribution

## TestFlight Beta Testing

1. Archive the app in Xcode
2. Upload to App Store Connect
3. Distribute to internal testers
4. After internal validation, distribute to external testers
5. Collect feedback via TestFlight

## App Store Submission

1. Ensure all screenshots are ready (watchOS and iOS)
2. Write App Store description and keywords
3. Set pricing and availability
4. Submit for review
5. Address any review feedback promptly

## Build Versioning

Use semantic versioning:

- `MAJOR.MINOR.PATCH`
- Increment `MAJOR` for significant feature releases
- Increment `MINOR` for new features
- Increment `PATCH` for bug fixes
